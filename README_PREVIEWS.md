# Preview integration checkpoint v0.3.2
All eight combat-only clips supplied from prior preview checkpoints. Each game ID maps to its own MP4 in Previews/.
Build_VS2022.bat copies these beside the compiled executable. PLAY GAME PREVIEW launches the selected game's clip in the default Windows media player. No embedded flip-card preview or auto-loop is implemented yet.
Original full-length uploads are not included and remain unchanged. EX games remain separate in the planned design, though the current foundation's game list shows all eight games.
